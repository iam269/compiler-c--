# C++ Online Compiler - AurelDev

A simple online C++ compiler with real-time execution and a modern dark-themed interface.

## 🚀 Features

- **Code editor** with basic syntax highlighting
- **Real-time execution** - code runs automatically after 500ms of typing pause
- **Run button** for manual code execution
- **Dark theme** for a comfortable experience
- **Colored output** for results

## 📁 Project Structure

```
compiler c++/
├── index.html   # Main HTML page structure
├── script.js    # JavaScript logic for compilation and execution
├── style.css    # CSS styles for visual appearance
└── README.md    # Project documentation
```

## 🛠️ Technologies Used

- **HTML5** - Page structure
- **CSS3** - Styles and responsive design
- **JavaScript (ES6+)** - Execution logic

## ⚠️ Limitations

This is a **simulated implementation** of a C++ compiler. It doesn't actually compile C++ code:

- Does not require a real C++ compiler installed
- Does not support all C++ language features
- Output is simulated based on keywords (e.g., `cout`)

## 📝 How to Use

1. Open `index.html` in a web browser
2. Write your C++ code in the editor on the left
3. Code will execute automatically or you can click the **Run Code** button
4. Results will appear on the right side in the Output section

## 🎨 Code Example

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Hello, Aurel!" << endl;
    return 0;
}
```
